# トバル2 モデルビューア

PlayStation 版『トバル2』のディスクイメージを読み込み、プレイアブルキャラクター10人の3Dモデルをブラウザで回して見るビューア（非公式）。

**https://haristweet.github.io/tobal2-model-viewer/**

## 使い方

1. 手持ちのトバル2（SLPM-86033）のディスクイメージをページにドロップするか、「ファイルを選ぶ」で選ぶ
   - `.chd`（MAME の圧縮形式・v5）
   - `.bin`（2352バイト/セクタの生イメージ、または 2048バイトの ISO）
   - ディスクから取り出した `ALLBIN.BIN` と `SLPM_860.33` の2つ
2. 左でキャラクター・1P/2P カラー・モデル（対戦／勝利／クエスト）・動きを選ぶ（技名の分かった動きは名前付き。再生・一時停止とコマ送りができる）
3. ドラッグで回転、右ドラッグ／Shift＋ドラッグ（中ボタンでも）で移動、ホイールでカーソル位置に向かって拡大、ダブルクリックで視点を戻す。タッチ操作は1本指で回転、2本指で移動と拡大

ゲームのデータはこのページに一切含まれていない。読み込んだファイルはブラウザの中だけで読み取り、どこにも送信しない。

## 中身

`index.html` の1枚のみ。外部ライブラリもビルドも無い（WebGL 直書き）。

- ディスク: ISO9660 を読んで `SYSTEM.CNF` を確認し、`ALLBIN.BIN` と実行ファイルを取り出す。必要なセクタだけ `Blob.slice` で読む
- CHD: ハンクの目次（ハフマン符号）を解き、`cdlz`（LZMA）と `cdzl`（Deflate）のハンクを展開する。`cdfl`（FLAC、音楽トラック用）と差分形式には未対応
- ファイル表: 実行ファイル内の表から `ALLBIN.BIN` 内の位置を引く
- 圧縮: ゲーム独自の圧縮（先頭 0x0b、4bit モードの256バイト単位ブロック）をゲームの展開処理と同じ結果になるよう移植
- モデル: 表示命令の列（関節選択・頂点変換・ポリゴン命令）をたどって三角形にする
- 骨格: 骨の長さの表と、プログラムに直書きされていた親子関係から T ポーズを組む
- テクスチャ: モデルファイル内の VRAM 転送列（4bit/8bit 画像とパレット）を仮想 VRAM に置き、パレット引きはシェーダで行う
- 動き: 読み込んだ実行ファイルの「モーション評価＋IK＋骨組み」の処理を、ページ内の小さな MIPS＋GTE エミュレータでそのまま実行して関節の行列を得る（実機の試合中のメモリと関節行列がビット単位で一致することを確認）。キャラごとのモーションファイルは実行ファイル内の表から
- 技の名前: モーションファイル内の技データ（段・威力・ヒットタイミング・ボタンごとの派生先）と、[tobal2 @ ウィキ](https://w.atwiki.jp/tobal2/) の技表（段・威力・ヒットタイミング・コマンド）を突き合わせて付けた。同じ数値の技はコマンド表（全キャラ共通の並び）で見分けている。名前が付いたのは各キャラ 27〜59 個（投げなどタイミングの載っていない技は未対応）

解析の経緯（DuckStation の GDB スタブを使ったメモリ・命令の追跡など）は別途の作業メモにまとめている。

## 未対応

- 投げ・やられ・移動などの名前、動きのつなぎ目の補間、頭を相手に向ける動作
- 眼球の視線、腰の布やしっぽのゆれ
- 半透明表現、モンスターなどプレイアブル以外のモデル

## 更新履歴（Changelog）

- **v1.3.1** (2026-09-14) — 単色の面（テクスチャなし）の色を修正。面のデータの語1は色ではなく「法線と色の番号」だった（ゲームの描画処理どおり、色の列から引くように）。チュージの耳まわりが黒くなっていたのが肌色に。
- **v1.3.0** (2026-09-14) — 視点の移動に対応（右ドラッグ／Shift＋ドラッグ、2本指）。ホイールの拡大をカーソル位置に向かうようにし、顔のアップまで寄れるようにした。
- **v1.2.1** (2026-09-14) — 顔などテクスチャ部分の色がくすんでいたのを修正。頂点色だけの面を明るくしすぎていたのをやめ、テクスチャ面（テクスチャ × 頂点色/128）と明るさの基準を揃えた。
- **v1.2.0** (2026-09-14) — 技の名前を表示（「名前のある技だけ」で絞り込み）。ホム・フェイ・マリー・イールのモーションファイルの割り当てが間違っていたのを修正（技表との照合で判明）。
- **v1.1.0** (2026-09-14) — 動きの再生に対応。キャラごとのモーションを番号で選んで再生・一時停止・コマ送りできる。ゲーム本体の処理をページ内のエミュレータで動かして関節を求めている。
- **v1.0.2** (2026-09-13) — モデル全体が左右反転していたのを修正。ホムの胸の漢字やドクターVのベルトの文字が正しく読める向きに。
- **v1.0.1** (2026-09-13) — 頭の位置に固まっていた小さな部品を正しい位置に。イールのしっぽ（5節、骨の表から組む）と、エポン・チャコ・グリンの 2P モデルの股下のすそ（左右の太ももの中間に付く頂点）。
- **v1.0.0** (2026-09-13) — 最初の公開。プレイアブル10人 × 1P/2P × 対戦・勝利・クエストの60モデル。テクスチャ、勝利モデルの眼球、腰の垂れ部品に対応。`.chd` / `.bin` / 取り出し済みファイルの読み込み。
