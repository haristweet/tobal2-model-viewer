# トバル2 モデルビューア

PlayStation 版『トバル2』のディスクイメージを読み込み、プレイアブルキャラクター10人の3Dモデルをブラウザで回して見るビューア（非公式）。

**https://haristweet.github.io/tobal2-model-viewer/**

## 使い方

1. 手持ちのトバル2（SLPM-86033）のディスクイメージをページにドロップするか、「ファイルを選ぶ」で選ぶ
   - `.chd`（MAME の圧縮形式・v5）
   - `.bin`（2352バイト/セクタの生イメージ、または 2048バイトの ISO）
   - ディスクから取り出した `ALLBIN.BIN` と `SLPM_860.33` の2つ
2. 左でキャラクター・1P/2P カラー・モデル（対戦／勝利／クエスト）を選ぶ
3. ドラッグで回転、ホイールで拡大、ダブルクリックで視点を戻す

ゲームのデータはこのページに一切含まれていない。読み込んだファイルはブラウザの中だけで読み取り、どこにも送信しない。

## 中身

`index.html` の1枚のみ。外部ライブラリもビルドも無い（WebGL 直書き）。

- ディスク: ISO9660 を読んで `SYSTEM.CNF` を確認し、`ALLBIN.BIN` と実行ファイルを取り出す。必要なセクタだけ `Blob.slice` で読む
- CHD: ハンクの目次（ハフマン符号）を解き、`cdlz`（LZMA）と `cdzl`（Deflate）のハンクを展開する。`cdfl`（FLAC、音楽トラック用）と差分形式には未対応
- ファイル表: 実行ファイル内の表から `ALLBIN.BIN` 内の位置を引く
- 圧縮: ゲーム独自の圧縮（先頭 0x0b、4bit モードの256バイト単位ブロック）をゲームの展開処理と同じ結果になるよう移植
- モデル: 表示命令の列（関節選択・頂点変換・ポリゴン命令）をたどって三角形にする
- 骨格: 骨の長さの表と、プログラムに直書きされていた親子関係から T ポーズを組む
- テクスチャ: モデルファイル内の VRAM 転送列（4bit/8bit 画像とパレット）を仮想 VRAM に置き、パレット引きはシェーダで行う

解析の経緯（DuckStation の GDB スタブを使ったメモリ・命令の追跡など）は別途の作業メモにまとめている。

## 未対応

- モーション（立ちポーズのみ）
- 眼球の視線、腰の布やしっぽのゆれ
- 半透明表現、モンスターなどプレイアブル以外のモデル
