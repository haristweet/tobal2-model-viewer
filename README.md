# トバル2 モデルビューア

PlayStation 版『トバル2』のディスクイメージを読み込み、プレイアブルキャラクター10人の3Dモデルをブラウザで回して見るビューア（非公式）。

**https://haristweet.github.io/tobal2-model-viewer/**

## 使い方

1. 手持ちのトバル2（SLPM-86033）のディスクイメージをページにドロップするか、「ファイルを選ぶ」で選ぶ
   - `.chd`（MAME の圧縮形式・v5）
   - `.bin`（2352バイト/セクタの生イメージ、または 2048バイトの ISO）
   - ディスクから取り出した `ALLBIN.BIN` と `SLPM_860.33` の2つ
2. 「BGM」で曲を選ぶとゲームの曲がループで流れる（.chd / .bin のとき。音量つまみあり）。左でキャラクター・1P/2P カラー・モデル（対戦／勝利／クエスト）・動きを選ぶ（技名の分かった動きは名前付き。再生・一時停止、◀ ▶ ボタンか ← → キーで1コマずつ送り、スペースで再生／一時停止）
3. 左上（スマホは右上）の丸で背景の色を選ぶ（ダーク・黒・グレー・白・空・夕焼け・夜・グリーンバック。選んだものは覚えておく）。右上の「スクショを保存」で今の表示を PNG で保存（「背景なし」で透明背景）。ドラッグで回転、右ドラッグ／Shift＋ドラッグ（中ボタンでも）で移動、ホイールでカーソル位置に向かって拡大、ダブルクリックで視点を戻す。タッチ操作は1本指で回転、2本指で移動と拡大、ダブルタップで戻す

ゲームのデータはこのページに一切含まれていない。読み込んだファイルはブラウザの中だけで読み取り、どこにも送信しない。

## 中身

`index.html` の1枚のみ。外部ライブラリもビルドも無い（WebGL 直書き）。

- ディスク: ISO9660 を読んで `SYSTEM.CNF` を確認し、`ALLBIN.BIN` と実行ファイルを取り出す。必要なセクタだけ `Blob.slice` で読む
- CHD: ハンクの目次（ハフマン符号）を解き、`cdlz`（LZMA）と `cdzl`（Deflate）のハンクを展開する。`cdfl`（FLAC、音楽トラック用）と差分形式には未対応
- ファイル表: 実行ファイル内の表から `ALLBIN.BIN` 内の位置を引く
- 圧縮: ゲーム独自の圧縮（先頭 0x0b、4bit モードの256バイト単位ブロック）をゲームの展開処理と同じ結果になるよう移植
- モデル: 表示命令の列（関節選択・頂点変換・ポリゴン命令）をたどって三角形にする
- 骨格: 骨の長さの表と、プログラムに直書きされていた親子関係から T ポーズを組む
- テクスチャ: モデルファイル内の VRAM 転送列（4bit/8bit 画像とパレット）を仮想 VRAM に置き、パレット引きはシェーダで行う
- 動き: 読み込んだ実行ファイルの「モーション評価＋IK＋骨組み」の処理を、ページ内の小さな MIPS＋GTE エミュレータでそのまま実行して関節の行列を得る（実機の試合中のメモリと関節行列がビット単位で一致することを確認）。キャラごとのモーションファイルは実行ファイル内の表から
- 勝利ポーズとダンス: キャラごとの勝利用ファイル（種類7、実行ファイルの表 0x800d3560 から）に、隠しダンス（250フレーム×5〜6に分割）と勝利ポーズ4種が入っている。ダンスは区切りを順につないで再生
- BGM: ディスクの BGM001〜003.XA（XA-ADPCM 4bit ステレオ 37.8kHz、8チャンネルを1セクタずつ交互に格納）をブラウザ内で展開し、Web Audio で約3秒先まで順に流す。曲の終わりで頭に戻る
- 技の名前: モーションファイル内の技データ（段・威力・ヒットタイミング・ボタンごとの派生先）と、[tobal2 @ ウィキ](https://w.atwiki.jp/tobal2/) の技表（段・威力・ヒットタイミング・コマンド）を突き合わせて付けた。同じ数値の技はコマンド表（全キャラ共通の並び）で見分けている。投げは技表の威力とコマンド表の「左つかみ・右つかみ・後ろ・押しながら」などの欄を突き合わせ、投げられる側の動き（投げのデータが指している）にも「（相手側）」として名前を付けた。さらにボタンの派生先をたどって連携技の途中も埋めている。名前が付いたのは各キャラ 41〜70 個。残りは技データの種類から「（構え）」「（投げ）」「〇〇の派生」「上段の技 威力20」などの説明を出す

解析の経緯（DuckStation の GDB スタブを使ったメモリ・命令の追跡など）は別途の作業メモにまとめている。

## 未対応

- やられ・移動の動きや一部の投げ（マリーの持ち上げからの連続投げなど）の名前、動きのつなぎ目の補間、頭を相手に向ける動作
- 眼球の視線、腰の布やしっぽのゆれ
- 半透明表現、モンスターなどプレイアブル以外のモデル

## 更新履歴（Changelog）

- **v2.2.0** (2026-09-14) — 名前の付いた動きを増やした（各キャラ 41〜70 個）。投げと投げられる側、連携技の途中を追加。名前の分からない動きにも「構え」「投げ」「〇〇の派生」「中段の技 威力35」などの説明を表示。
- **v2.1.0** (2026-09-14) — 「なめらかな陰影」を追加（グーロー面の法線を同じ位置の頂点で平均。オンにするとのっぺりしたカクカク感が減る。単色の面はゲームどおり平らなまま）。設定は次回も保持。
- **v2.0.0** (2026-09-14) — スマホの画面を作り直し。3D を全画面にし、操作は下のタブ（キャラ／技／背景・BGM）から引き出すシートに。技は押しやすい行の一覧から選び、再生バーは表示の下に浮かせる。
- **v1.9.0** (2026-09-14) — 背景の色をプリセットから選べるように（8種、スクショにも反映、次回も同じ背景）。
- **v1.8.0** (2026-09-14) — 勝利ポーズ4種と隠しダンスを追加（動きの一覧の「勝利」）。ダンスは5〜6個に分かれた動きを続けて再生。
- **v1.7.0** (2026-09-14) — BGM を流せるように（ディスクの24曲、ループ再生、音量）。
- **v1.6.0** (2026-09-14) — iPhone などスマホ向けの画面に。表示を上に大きく、操作を下にまとめ、キャラは横スクロールで選ぶ。ダブルタップで視点を戻す、縦長の画面では全身が入るよう引く、スクショは共有シートから「画像を保存」できる。古い iOS で CHD が読めないときは理由を表示。
- **v1.5.0** (2026-09-14) — スクショの保存（PNG、背景あり／透明を選べる。ファイル名にキャラ・技名・コマ番号）。
- **v1.4.0** (2026-09-14) — 動きのコマ送りボタン（◀ ▶）とキー操作（← → で1コマ、スペースで再生／一時停止）を追加。
- **v1.3.1** (2026-09-14) — 単色の面（テクスチャなし）の色を修正。面のデータの語1は色ではなく「法線と色の番号」だった（ゲームの描画処理どおり、色の列から引くように）。チュージの耳まわりが黒くなっていたのが肌色に。
- **v1.3.0** (2026-09-14) — 視点の移動に対応（右ドラッグ／Shift＋ドラッグ、2本指）。ホイールの拡大をカーソル位置に向かうようにし、顔のアップまで寄れるようにした。
- **v1.2.1** (2026-09-14) — 顔などテクスチャ部分の色がくすんでいたのを修正。頂点色だけの面を明るくしすぎていたのをやめ、テクスチャ面（テクスチャ × 頂点色/128）と明るさの基準を揃えた。
- **v1.2.0** (2026-09-14) — 技の名前を表示（「名前のある技だけ」で絞り込み）。ホム・フェイ・マリー・イールのモーションファイルの割り当てが間違っていたのを修正（技表との照合で判明）。
- **v1.1.0** (2026-09-14) — 動きの再生に対応。キャラごとのモーションを番号で選んで再生・一時停止・コマ送りできる。ゲーム本体の処理をページ内のエミュレータで動かして関節を求めている。
- **v1.0.2** (2026-09-13) — モデル全体が左右反転していたのを修正。ホムの胸の漢字やドクターVのベルトの文字が正しく読める向きに。
- **v1.0.1** (2026-09-13) — 頭の位置に固まっていた小さな部品を正しい位置に。イールのしっぽ（5節、骨の表から組む）と、エポン・チャコ・グリンの 2P モデルの股下のすそ（左右の太ももの中間に付く頂点）。
- **v1.0.0** (2026-09-13) — 最初の公開。プレイアブル10人 × 1P/2P × 対戦・勝利・クエストの60モデル。テクスチャ、勝利モデルの眼球、腰の垂れ部品に対応。`.chd` / `.bin` / 取り出し済みファイルの読み込み。
